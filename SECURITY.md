# Security policy

Do not put cookies, passwords, access tokens, or private URLs in a public issue.

For a suspected security problem, contact the repository owner through GitHub before publishing details. Include the affected version, platform, reproduction steps, and the smallest useful log excerpt after removing credentials.

DLP stores browser-cookie selections and cookie-file paths. It does not store cookie contents or credentials. The project does not promise that downloaded media is lawful to copy; follow the source site's terms and applicable law.
